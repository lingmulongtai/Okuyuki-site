# Okuyuki-site

[Okuyuki](https://github.com/lingmulongtai/Okuyuki-android) の紹介サイトです。ビルド不要の静的ページ（`index.html` 1 枚）で、GitHub Pages でそのまま配信できます。

- 確認: `npm install && npx playwright install chromium && npm test`（スマホ幅 390px と PC 幅で、ライト／ダークの両方を確認し、スクリーンショットを `test-results/` に残します）
- 画面の絵は、アプリの実際の画面をもとに HTML で描いたイメージです。アプリの UI の仕上げが終わったら、実際の画面に合わせて更新します。
